# Useful Helicopters Experimental (0.G optional backport)

This optional mod contains the parts of the Cataclysm-2040 Useful Helicopters patch that are
actually present in its 0.G payload:

- A zero-point `Piloting (Useful Helicopters)` hobby with helicopter-pilot proficiency.
- A zero-point `Airframe and Powerplant Mechanic` hobby with aircraft-mechanic proficiency.
- Repairable, removable and installable definitions for the 15 m military, 8 m civilian,
  16 m Blackhawk and 11 m Osprey rotor variants.

The normal 0.G Piloting hobby is unchanged. Enable this mod at world creation if you want these
optional helicopter rules.

This payload does **not** change turbine fuel consumption, alter existing pilot professions, add a
Pilot Package CBM, or add recipes that train either proficiency.
